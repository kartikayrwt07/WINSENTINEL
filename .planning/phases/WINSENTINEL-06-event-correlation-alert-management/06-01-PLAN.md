<objective>
Implement the compound incident model, 4 core multi-stage attack chain definitions, and the lineage-aware AttackChainEngine for WinSentinel.

Purpose: WinSentinel requires elevating isolated detection alerts into connected multi-stage threat intelligence (CORR-01, CORR-02, CORR-04). By traversing process lineage DAGs (`ProcessTreeGraph`) across a 30-minute sliding window scoped by host and user, WinSentinel identifies connected attack campaigns (Phishing, Web Shell, Credential Dumping -> Lateral, LotL -> Persistence) and automatically promotes them to `Critical` severity `CompoundIncident`s with human-readable chronological narratives.
Output: `app/models/incident.py`, `app/correlation/__init__.py`, `app/correlation/chains.py`, `app/correlation/chain_engine.py`, and test suites in `tests/unit/test_compound_incident.py`, `tests/unit/test_attack_chains.py`, and `tests/unit/test_chain_engine.py`.
</objective>

class IncidentStage(BaseModel):
    model_config = ConfigDict(frozen=True)
    stage_number: int
    stage_name: str
    tactic: str
    technique: str
    timestamp: datetime
    process_guid: str | None = None
    image: str | None = None
    command_line: str | None = None
    event_ids: list[int] = Field(default_factory=list)
    alert_ids: list[int] = Field(default_factory=list)
    narrative: str

class CompoundIncident(BaseModel):
    model_config = ConfigDict(frozen=True)
    incident_id: str
    chain_id: str
    chain_name: str
    severity: str = "Critical"
    status: str = "New"
    computer: str
    user: str | None = None
    first_seen: datetime
    last_seen: datetime
    stages: list[IncidentStage]
    participating_alert_ids: list[int] = Field(default_factory=list)
    participating_event_ids: list[int] = Field(default_factory=list)
    summary_narrative: str
    mitre_tactics: list[str] = Field(default_factory=list)
    mitre_techniques: list[str] = Field(default_factory=list)
    def to_investigation_dict(self) -> dict[str, Any]: ...
    def to_alert_dict(self) -> dict[str, Any]: ...
    def to_evidence_dicts(self, alert_id: int) -> list[dict[str, Any]]: ...

class ChainStageDefinition(BaseModel):
    stage_number: int
    stage_name: str
    tactic: str
    technique: str
    requires_lineage: bool = True
    description: str

class AttackChainDefinition(BaseModel):
    chain_id: str
    name: str
    description: str
    mitre_tactics: list[str]
    mitre_techniques: list[str]
    window_minutes: int = 30
    stages: list[ChainStageDefinition]

class AttackChainEngine:
    def __init__(self, chains: list[AttackChainDefinition] | None = None, default_window_minutes: int = 30) -> None: ...
    def correlate(
        self,
        events: list[NormalizedEvent],
        alerts: list[dict[str, Any]] | None = None,
        process_tree: ProcessTreeGraph | None = None,
    ) -> list[CompoundIncident]: ...

      - `__init__(self, chains: list[AttackChainDefinition] | None = None, default_window_minutes: int = 30)`:
        - Stores configured chains (defaults to `get_default_attack_chains()`).
        - Sets sliding temporal window limit (default 30 min).
      - `correlate(self, events: list[NormalizedEvent], alerts: list[dict[str, Any]] | None = None, process_tree: ProcessTreeGraph | None = None) -> list[CompoundIncident]`:
        - If `process_tree` is None, constructs one from process events in `events`.
        - Normalizes all event timestamps to UTC datetimes.
        - Partitions telemetry by `(computer)`.
        - Sorts events chronologically by `timestamp`.
        - For each host partition, iterates through active chain definitions:
          - Evaluates Stage 1 candidate events.
          - For each Stage 1 match $E_1$:
            - Computes window cutoff: $t_{max} = E_1.timestamp + \text{timedelta}(minutes=chain.window\_minutes)$.
            - Filters candidate subsequent events satisfying $E_1.timestamp \le E_i.timestamp \le t_{max}$.
            - If `stage.requires_lineage`:
              - Checks whether $E_i.process_guid$ is in $E_1$'s descendants via `process_tree.get_descendants(E_1.process_guid)` or equals $E_1.process_guid$.
            - Matches each successive stage in chain order.
            - If all stages are satisfied:
              - Synthesizes `IncidentStage` objects with narratives, tactics, techniques, and event/alert IDs.
              - Constructs `CompoundIncident` with `severity="Critical"`, `status="New"`, and full narrative generated by `generate_incident_narrative()`.
              - Deduplicates incidents by `(chain.chain_id, computer, root_process_guid)` to avoid redundant records for the same attack chain.
        - Returns list of generated `CompoundIncident`s.
