<objective>
Implement the repository access layer, high-throughput bulk ingestion engine, dynamic parameterized query builder, and pipeline database integration for WinSentinel.

Purpose: WinSentinel requires a robust forensic data access layer capable of ingesting thousands of normalized events in bulk transactions (D-02), suppressing duplicates atomically, and supporting dynamic forensic queries with total record counts and pagination (D-04) without SQL injection vulnerabilities (ALERT-01). Connecting this layer to the Phase 1 IngestionPipeline completes the end-to-end telemetry persistence cycle.
Output: `app/database/repository.py`, `app/database/query.py`, updated `app/ingestion/pipeline.py`, and test suites in `tests/unit/` and `tests/integration/`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User / Web UI Search Parameters → Query Builder | Filter inputs containing arbitrary attacker-controlled strings |
| Ingestion Telemetry Stream → Bulk Database Insert | Telemetry payload fields inserted into relational database columns |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering / Information Disclosure | `app/database/query.py` | mitigate | Dynamic query builder uses 100% parameterization (`?` placeholders). Filter column names are strictly fixed in code and allowlisted. No user parameter is ever interpolated into SQL text. |
| T-02-05 | Denial of Service | `app/database/repository.py` | mitigate | Batch insertions are bounded to 1,000-event chunks per transaction to prevent excessive memory usage and lock monopolization. Queries enforce mandatory `LIMIT` and `OFFSET` clauses. |
| T-02-06 | Tampering | `app/database/repository.py` | mitigate | Store raw uncompressed payload alongside normalized fields in `raw_payload`, bound to deterministic `event_hash` for forensic integrity and tamper evidence. |
</threat_model>
