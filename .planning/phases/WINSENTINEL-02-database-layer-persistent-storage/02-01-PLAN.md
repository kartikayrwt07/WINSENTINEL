<objective>
Implement the SQLite database infrastructure, connection management, schema DDL, and transactional migration runner for WinSentinel.

Purpose: WinSentinel requires a high-performance, embedded, crash-resilient persistence layer (ALERT-01). Operating in SQLite WAL mode with foreign key enforcement and busy waiting enables non-blocking concurrent reads and writes for SOC triage (D-01). A zero-dependency versioned migration runner executes sequential `.sql` migration scripts tracked in `schema_migrations` (D-03) to establish the complete 12-table relational foundation without third-party ORM overhead.
Output: `app/config.py`, `app/database/connection.py`, `app/database/migrations/001_initial_schema.sql`, `app/database/migrations.py`, and comprehensive unit tests in `tests/unit/`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application Threads → Database Connection Pool | Concurrent worker threads and UI sessions accessing SQLite file simultaneously |
| External Filesystem → Migration Runner | SQL migration scripts loaded from disk and executed into the database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | `app/database/connection.py` | mitigate | Configure WAL journal mode, `PRAGMA busy_timeout = 5000;`, and `PRAGMA synchronous = NORMAL;`. Isolate connection objects per thread (`check_same_thread=True`) to prevent lock contention crashes and thread race conditions. |
| T-02-02 | Tampering | `app/database/migrations.py` | mitigate | Compute SHA-256 checksums of migration files and verify against stored records in `schema_migrations` before applying new migrations. Execute migrations transactionally to prevent partial schema corruption. |
| T-02-03 | Elevation of Privilege | `app/database/connection.py` | mitigate | Enforce `PRAGMA foreign_keys = ON;` on every opened connection to ensure relational integrity cannot be bypassed. |
</threat_model>
