<description>
Implement mathematical confusion matrix calculation and metric synthesis in `app/evaluation/metrics.py`:
1. `calculate_metrics(matrix: ConfusionMatrix) -> tuple[float, float, float, float, float]`:
   - Returns `(precision, recall, f1_score, fpr, accuracy)`
   - Safe zero-division handling:
     - Precision: `1.0` if `(tp + fp) == 0` else `tp / (tp + fp)`
     - Recall: `1.0` if `(tp + fn) == 0` else `tp / (tp + fn)`
     - F1-Score: `0.0` if `(precision + recall) == 0.0` else `2 * (precision * recall) / (precision + recall)`
     - FPR: `0.0` if `(fp + tn) == 0` else `fp / (fp + tn)`
     - Accuracy: `0.0` if `total == 0` else `(tp + tn) / total`
2. `build_rule_metrics(rule_id: str, rule_title: str, severity: str, matrix: ConfusionMatrix, fpr_threshold: float = 0.05, precision_threshold: float = 0.80) -> RuleEvaluationMetrics`:
   - Computes metrics and sets `is_dead = (matrix.tp == 0 and matrix.fp == 0)` and `is_noisy = (fpr > fpr_threshold or (matrix.tp + matrix.fp > 0 and precision < precision_threshold))`.
3. `aggregate_matrices(matrices: list[ConfusionMatrix]) -> ConfusionMatrix`:
   - Sums up tp, fp, tn, fn across rules.
Create unit tests in `tests/unit/test_confusion_matrix.py` covering:
- Standard scenarios with known values.
- Perfect accuracy (100% TP, 0 FP/FN).
- Worst-case noisy detector (0 TP, all FP).
- Completely dead rule (0 TP, 0 FP, 0 FN, all TN).
- Zero denominator edge cases for all 5 metrics.
</description>

Run `python -m pytest tests/unit/test_confusion_matrix.py -v` to verify mathematical correctness.
