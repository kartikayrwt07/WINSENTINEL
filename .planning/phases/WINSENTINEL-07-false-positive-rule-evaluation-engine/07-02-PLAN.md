<description>
Implement `EvaluationRunner` in `app/evaluation/runner.py`:
1. `class EvaluationRunner`:
   - `__init__(engine: DetectionEngine | None = None, rules: list[DetectionRule] | None = None)`
   - `run_evaluation(dataset: list[BenchmarkEvent] | Path | str, dataset_name: str = "") -> EvaluationReport`:
     - Loads dataset via `load_benchmark_dataset` if path is provided.
     - For each rule in engine:
       - Initializes a `ConfusionMatrix()`.
     - For each `BenchmarkEvent` in dataset:
       - Extracts `event = benchmark_event.event` and `label = benchmark_event.label`.
       - Obtains matches: `matches = engine.evaluate_event(event)`.
       - Determines matched rule IDs: `matched_rule_ids = {m.rule_id for m in matches}`.
       - Expected rule IDs: `expected_rule_ids = set(label.expected_rules)`.
       - For each registered rule $R$:
         - `is_matched = R.id in matched_rule_ids`
         - `is_expected = R.id in expected_rule_ids`
         - If `is_matched and is_expected`: increment `matrix.tp`
         - If `is_matched and not is_expected`: increment `matrix.fp` (and store event in FP sample cache for tuner)
         - If `not is_matched and is_expected`: increment `matrix.fn`
         - If `not is_matched and not is_expected`: increment `matrix.tn`
     - Computes `RuleEvaluationMetrics` for each rule.
     - Computes aggregated `overall_matrix` and global precision, recall, f1, fpr.
     - Calls `RuleTuner.analyze(rule_metrics, fp_samples)` to generate tuning recommendations.
     - Constructs and returns `EvaluationReport`.
2. Unit tests in `tests/unit/test_evaluation_runner.py`:
   - Mock engine and synthetic benchmark events to verify exact TP/FP/TN/FN bookkeeping.
   - Tests runner with empty dataset, single rule, and multiple rules.
   - Validates that runner does not touch SQLite database files.
</description>

<description>
Implement heuristic rule health analyzer `RuleTuner` in `app/evaluation/tuner.py`:
1. `class RuleTuner`:
   - Configurable thresholds: `max_fpr: float = 0.05`, `min_precision: float = 0.80`.
   - `analyze_rules(rule_metrics: dict[str, RuleEvaluationMetrics], fp_samples: dict[str, list[NormalizedEvent]]) -> list[TuningRecommendation]`:
     - Checks each rule:
       1. **Dead Rule**: If `matrix.tp == 0 and matrix.fp == 0 and (matrix.fn > 0 or total_attacks > 0)`:
          - Generates recommendation: `issue="ZERO_COVERAGE"`, `severity="MEDIUM"`, suggesting authoring test telemetry or verifying rule condition syntax.
       2. **High FPR**: If `false_positive_rate > max_fpr`:
          - Generates recommendation: `issue="HIGH_FALSE_POSITIVE_RATE"`, `severity="HIGH"`.
       3. **Low Precision**: If `precision < min_precision and (matrix.tp + matrix.fp) > 0`:
          - Generates recommendation: `issue="LOW_PRECISION"`, `severity="HIGH"`.
     - Synthesizes suppression suggestions for noisy rules:
       - Inspects `fp_samples[rule_id]` for recurring field values:
         - Parent image (`parent_image`), Image path (`image`), User (`user`), Command line patterns (`command_line`).
         - If a specific field value appears in $>60\%$ of false positive events, adds suggested suppression rule block (e.g. `Filter out parent_image: 'C:\\Windows\\CCM\\CcmExec.exe'`).
2. Unit tests in `tests/unit/test_rule_tuner.py`:
   - Tests dead rule detection.
   - Tests noisy rule detection with high FPR.
   - Tests suppression candidate synthesis when FP events share common `parent_image` or `user`.
</description>
