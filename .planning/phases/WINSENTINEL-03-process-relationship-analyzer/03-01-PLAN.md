<objective>
Implement the core process tree data structures, NetworkX directed graph representation, deterministic synthetic GUID generator, temporal PID reuse resolver, and SQLite process repository for WinSentinel.

Purpose: WinSentinel requires converting flat, point-in-time process events into directed execution hierarchies (PROC-01). Because Windows OS aggressively recycles numerical PIDs, the system must scope processes by temporal lifespans [start_time, end_time] (PROC-02, D-03). To unify non-Sysmon events (Security 4688) with Sysmon telemetry, deterministic UUID5 keys are generated (D-01). Missing parent creation events are handled via synthesized placeholder parent nodes (PROC-03, D-02). Persistent storage in SQLite enables downstream graph hydration and analysis (ALERT-01, PROC-05).
Output: `app/analyzers/process_analyzer.py`, `app/analyzers/pid_resolver.py`, `app/database/migrations/002_process_lineage_metadata.sql`, `app/database/repository.py` extension, and corresponding unit test suites.
</objective>

      - `__init__(self) -> None`:
        - Initialize `self._index: dict[tuple[str, int], list[ProcessLifespan]] = {}`.
      - `register_process_creation(self, node: ProcessNode) -> None`:
        - Key: `(node.computer.strip().lower(), node.process_id)`.
        - Retrieve or initialize list in `self._index`.
        - If previous lifespan in list has `end_time is None` or `end_time > node.start_time`:
          - Retroactively cap previous lifespan at `end_time = node.start_time`.
          - Replace previous lifespan tuple with capped version.
        - Append new `ProcessLifespan(start_time=node.start_time, end_time=node.end_time, node=node)`.
        - Ensure list remains sorted by `start_time` (maintain invariant or sort).
      - `register_process_termination(self, computer: str, pid: int, termination_time: datetime, process_guid: str | None = None) -> ProcessNode | None`:

        - Search lifespans in reverse order.
        - If `process_guid` is provided: locate matching `item.node.process_guid == process_guid`. Update `end_time = termination_time`. Update node copy with `end_time`. Return updated node.
        - If `process_guid` not provided: locate most recent lifespan where `start_time <= termination_time` and `(end_time is None or end_time >= termination_time)`. Update `end_time = termination_time`. Return updated node.
        - Return `None` if no matching lifespan found.
      - `resolve(self, computer: str, pid: int, timestamp: datetime) -> ProcessNode | None`:
        - Key: `(computer.strip().lower(), pid)`.
        - Retrieve `lifespans = self._index.get(key)`. If empty/None, return `None`.
        - Extract `starts = [item.start_time for item in lifespans]`.
        - Use `idx = bisect.bisect_right(starts, timestamp) - 1`.
        - If `idx >= 0`:
          - `candidate = lifespans[idx]`
          - If `candidate.start_time <= timestamp and (candidate.end_time is None or candidate.end_time >= timestamp)`:
            - Return `candidate.node`.
        - Return `None`.
