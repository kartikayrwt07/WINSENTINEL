<objective>
Implement the suspicious parent-child lineage anomaly detector, process tree graph serialization formats, and pipeline integration for WinSentinel.

Purpose: Threat actors commonly abuse legitimate system processes and office applications to execute shells and download cradles (PROC-04, D-04). WinSentinel must automatically detect these anomalous lineages across the MITRE ATT&CK matrix (T1059, T1204, T1190, T1068) and produce structured, explainable findings. Furthermore, process trees must be serializable into portable representations (Node-Link, Cytoscape, D3 hierarchical JSON) for downstream UI visualization in Phase 8 (PROC-05). Integrating this analyzer into `IngestionPipeline.ingest_and_persist` completes automated process tree reconstruction and database persistence.
Output: `app/analyzers/lineage_detector.py`, updated `app/analyzers/process_analyzer.py`, integrated `app/ingestion/pipeline.py`, and corresponding unit and integration test suites.
</objective>
