<objective>
Implement the safe PowerShell de-obfuscation engine, PowerShell analysis data models, and composite risk scoring analyzer for WinSentinel.

Purpose: PowerShell is the primary living-off-the-land (LotL) execution tool exploited by adversaries on Windows systems. WinSentinel requires a safe, zero-eval de-obfuscation engine (PWSH-01, PWSH-04) and a composite risk scoring analyzer (PWSH-02, PWSH-03, PWSH-05) that accurately identifies malicious command lines and script blocks (EID 4104) while eliminating false positives on routine administrative scripts through contextual baseline offsets and safety overrides.
Output: `app/analyzers/powershell_deobfuscator.py`, `app/models/powershell.py`, `app/analyzers/powershell_analyzer.py`, and comprehensive unit test suites in `tests/unit/test_powershell_deobfuscator.py` and `tests/unit/test_powershell_analyzer.py`.
</objective>

    - Implement `PowerShellDeobfuscator`:
      - Regex pattern for Base64 flags:
        `BASE64_FLAG_PATTERN = re.compile(r'(?:^|\s)(?:-|/)(?:enc(?:odedcommand)?|e)(?::|\s+|=)\s*["\']?([A-Za-z0-9+/=]{4,})["\']?', re.IGNORECASE)`
      - `repair_base64_padding(b64_str: str) -> str`:
        Strips whitespace and non-base64 characters, calculates `missing = (4 - len(clean) % 4) % 4`, returns `clean + ('=' * missing)`.
      - `decode_base64_payload(b64_str: str) -> str | None`:
        Repairs padding, runs `base64.b64decode(repaired)`.
        First attempts `raw_bytes.decode('utf-16-le')`. Check if decoded string has null characters or is readable.
        If decode fails or contains `\x00` in odd positions, attempts `raw_bytes.decode('utf-8')`.
        Fallback to `raw_bytes.decode('latin-1', errors='replace')`.
        Traps `binascii.Error`, `ValueError` and returns `None`.
      - `strip_backticks(text: str) -> str`:
        Replaces `` `([a-zA-Z0-9_\-\"\'\$]) `` with `\1`.
      - `flatten_concatenation(text: str) -> str`:
        Runs regex replacement `(["\'])\s*\+\s*\1` to remove `'+'` or `"+"`, iteratively up to 10 passes until string stabilizes.
      - `detect_format_operator(text: str) -> bool`:
        Detects `-f` format operator with positional braces (e.g., `re.search(r'["\'].*\{\d+\}.*["\']\s+-f\s+', text, re.IGNORECASE)`).
      - `deobfuscate(text: str) -> DeobfuscationResult`:
        Runs extraction, Base64 decoding, backtick stripping, concat flattening, and returns `DeobfuscationResult`. If Base64 is present and decoded, normalization is applied to both the decoded text and the outer text.
