<objective>
Define the core typed event representation, deduplication fingerprinting, and import statistics auditing models for WinSentinel.

Purpose: Telemetry from Windows Sysmon, Security, and PowerShell event logs must be structured into an immutable, strictly-typed Pydantic v2 schema (`NormalizedEvent`) that preserves the uncompressed `raw_payload` (D-02) for forensic evidence provenance, normalizes heterogeneous timestamp and hash formats, enables deterministic SHA-256 deduplication (D-04), and tracks import metrics and quarantine diagnostics (D-03).
Output: Pydantic v2 data models in `app/models/`, deduplication utility in `app/models/fingerprint.py`, and comprehensive unit tests in `tests/unit/`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Raw Log Files → Pydantic Models | Hostile/corrupted event strings and spoofed attributes enter application memory |
| Untrusted Payloads → Hash Fingerprinting | Pathological Unicode surrogates or huge payloads could cause decode crashes or CPU denial of service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | `app/models/events.py` | mitigate | Enforce `frozen=True` and `extra="ignore"` on `NormalizedEvent` to prevent downstream mutation or code injection through schema attributes. |
| T-01-02 | Denial of Service | `app/models/fingerprint.py` | mitigate | Use `errors="replace"` on UTF-8 encoding in `compute_event_fingerprint` to prevent unhandled `UnicodeDecodeError` crashes on hostile surrogates. |
| T-01-03 | Repudiation | `app/models/events.py` | mitigate | Retain raw uncompressed event payload in `raw_payload` (D-02) to preserve forensic provenance and non-repudiation. |
| T-01-SC | Tampering | pip dependencies | mitigate | Pin minimal known-safe dependency versions in `pyproject.toml` (`pydantic>=2.7`, `python-evtx>=0.8.1`, `pytest>=8.0`). |
</threat_model>
