<objective>
Implement specialized event normalizers for Sysmon, Windows Security, and PowerShell, wire the unified end-to-end Ingestion Pipeline, and validate the complete Phase 1 telemetry engine against synthetic test fixtures.

Purpose: Raw event records from diverse Windows logging subsystems have disparate schemas, conventions (hex vs. decimal PIDs), and field names. This plan provides the normalizer implementations mapping them into the uniform `NormalizedEvent` contract (NORM-02 through NORM-07) and wires the end-to-end `IngestionPipeline` (INGEST-01 to INGEST-06, NORM-01, NORM-08).
Output: Normalizer suite in `app/normalization/`, pipeline orchestrator in `app/ingestion/pipeline.py`, synthetic test fixtures in `sample_data/`, unit tests, and integration tests.
</objective>

class BaseNormalizer(ABC):
    @abstractmethod
    def normalize(self, system_fields: dict[str, str], data_fields: dict[str, str], raw_payload: str) -> NormalizedEvent:
        pass

class SysmonNormalizer(BaseNormalizer):
    def normalize(...) -> NormalizedEvent: ...

class SecurityNormalizer(BaseNormalizer):
    def normalize(...) -> NormalizedEvent: ...

class PowerShellNormalizer(BaseNormalizer):
    def normalize(...) -> NormalizedEvent: ...

class NormalizerDispatcher:
    def dispatch(self, system_fields: dict[str, str], data_fields: dict[str, str], raw_payload: str) -> NormalizedEvent: ...

class IngestionPipeline:
    def ingest_file(self, file_path: str | Path, base_dir: Path | None = None) -> tuple[list[NormalizedEvent], ImportStatistics]: ...

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parser Output → Normalizer Dispatcher | Field dictionaries extracted from untrusted event payloads are normalized |
| Normalizer Output → Pipeline Deduplication | In-memory SHA-256 fingerprint tracking stores event identifiers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Denial of Service | `app/normalization/security.py` | mitigate | Safely parse hex and decimal PIDs with fallback to `None` on invalid strings (`parse_hex_or_dec_int`) to prevent unhandled exception crashes. |
| T-01-09 | Tampering / Repudiation | `app/ingestion/pipeline.py` | mitigate | Calculate SHA-256 fingerprint including raw payload (D-04). Suppress duplicates while preserving full raw payload in `NormalizedEvent.raw_payload` (D-02). |
| T-01-10 | Information Disclosure | `app/ingestion/pipeline.py` | mitigate | Sanitized error reporting: log diagnostic error messages into `ImportStatistics` without executing or rendering unescaped script blocks or shell commands. |
| T-01-SC | Tampering | pip dependencies | mitigate | Use standard library `hashlib`, `xml.etree.ElementTree`, and verified pure-Python packages. |
</threat_model>
