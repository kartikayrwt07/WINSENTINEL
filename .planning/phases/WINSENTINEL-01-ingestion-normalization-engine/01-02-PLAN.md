<objective>
Build the streaming ingestion engine and file parsers for Windows EVTX binary logs, XML exports, and JSON dumps with safe path sanitization and corruption resilience.

Purpose: WinSentinel must ingest forensic log files of arbitrary size without exhausting RAM, crashing on malformed/truncated records (INGEST-01, INGEST-02, INGEST-03), or allowing security compromises like path traversal or XXE expansion (INGEST-06, D-01).
Output: Input sanitization utilities in `app/utils/security.py`, parser hierarchy in `app/ingestion/`, and unit test suites in `tests/unit/`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User File Input → OS Filesystem | Untrusted file paths passed from CLI, dashboard, or API cross to filesystem |
| Untrusted File Content → Parsers | Potentially corrupt or malicious EVTX/XML/JSON files enter memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Elevation of Privilege | `app/utils/security.py` | mitigate | Prevent path traversal attacks using `Path(p).resolve()` and `is_relative_to(base_dir)`. Disallow symlink directory escapes and run with standard user privileges (no admin required, INGEST-06). |
| T-01-05 | Denial of Service | `app/utils/security.py` | mitigate | Enforce maximum file size quotas (default 2GB for EVTX, 500MB for XML/JSON) prior to loading or parsing. |
| T-01-06 | Denial of Service | `app/ingestion/evtx_parser.py` | mitigate | Stream EVTX records chunk-by-chunk using `Evtx.chunks()` generator and mmap, preventing RAM exhaustion on large event files (D-01). |
| T-01-07 | Tampering / DoS | `app/ingestion/xml_parser.py` | mitigate | Prevent XXE entity expansion attacks by using standard ElementTree without external entity resolution. Use UTF-8 decode with `errors="replace"`. |
</threat_model>
