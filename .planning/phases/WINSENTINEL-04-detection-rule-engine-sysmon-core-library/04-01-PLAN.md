<objective>
Implement the foundational detection rule schema, zero-eval recursive-descent boolean AST condition parser, and directory rule loader for WinSentinel.

Purpose: WinSentinel requires a Sigma-inspired YAML detection rule representation (RULE-01) with strict validation, zero-eval recursive-descent boolean evaluation to prevent arbitrary code execution (D-01, RULE-02), and a robust rule loader that scans rule files, validates uniqueness, and synchronizes definitions to the relational database.
Output: `app/models/rule.py`, `app/detection/__init__.py`, `app/detection/ast_parser.py`, `app/detection/loader.py`, and comprehensive unit test suites.
</objective>

DetectionRule(BaseModel):
  id: str
  title: str
  description: str
  author: str = "WinSentinel Team"
  severity: RuleSeverity = RuleSeverity.MEDIUM

  investigation_steps: list[str] = Field(default_factory=list)
  raw_yaml: str = ""

ASTNode (ABC):
  def evaluate(self, context: dict[str, bool]) -> bool: ...

IdentifierNode(ASTNode):
  name: str
  def evaluate(self, context: dict[str, bool]) -> bool: ...

NotNode(ASTNode):
  operand: ASTNode
  def evaluate(self, context: dict[str, bool]) -> bool: ...

AndNode(ASTNode):
  left: ASTNode
  right: ASTNode
  def evaluate(self, context: dict[str, bool]) -> bool: ...

OrNode(ASTNode):
  left: ASTNode
  right: ASTNode
  def evaluate(self, context: dict[str, bool]) -> bool: ...

QuantifierNode(ASTNode):
  quantifier: Literal["1 of", "all of"]
  pattern: str
  def evaluate(self, context: dict[str, bool]) -> bool: ...

ConditionParser:
  def tokenize(self, expression: str) -> list[Token]: ...

  def load_rules_from_directory(self, directory: Path | str) -> list[DetectionRule]: ...
