      - `resolve_field_value(self, event: NormalizedEvent, raw_field: str) -> Any`:

          - Else (implicit OR):

        - On match: record `EvidenceItem(field=base_field, actual_value=actual_value, matched_pattern=matched_pat, modifier="|".join(modifiers) or "exact")`.

      - Method `match(event: NormalizedEvent, event_db_id: int | None = None) -> DetectionMatch | None`:
        - Evaluate each selection block in `self.selections`:
          - `is_match, evidence = self.matcher.match_selection(event, selection_dict)`

            `rule_id=self.rule.id, rule_title=self.rule.title, severity=self.rule.severity.value, event_id=event.event_id, event_record_id=event.record_id, event_db_id=event_db_id, computer=event.computer, timestamp_utc=event.timestamp, process_guid=event.process_guid, user=event.user, matched_evidence=matching_evidence, explanation=generate_explanation(...), mitre_tactics=[...], mitre_techniques=self.rule.mitre_attack, investigation_steps=self.rule.investigation_steps`.

    - Implement `DetectionEngine`:
      - `__init__(self)`:
        - `self._matcher = FieldMatcher()`
        - `self._parser = ConditionParser()`
        - `self._index: dict[tuple[str, int], list[CompiledRule]] = defaultdict(list)`
        - `self._universal_rules: list[CompiledRule] = []`
        - `self._rules: dict[str, CompiledRule] = {}`
      - `register_rule(self, rule: DetectionRule) -> None`:
        - Compile AST using `self._parser.parse(rule.detection.condition)`.
        - Separate selection and filter dictionaries from `rule.detection.selections`.
        - Create `CompiledRule(rule=rule, ast_root=ast, selections=rule.detection.selections, matcher=self._matcher)`.
        - Store in `self._rules[rule.id] = compiled`.
        - Index by logsource:
          - Extract target event_ids from `rule.logsource.event_id` (int or list of ints).
          - Extract provider from `rule.logsource.service or rule.logsource.product or ""`. Normalize with `.strip().lower()`.

          - Else, for each eid in target event_ids:
            - Add to `self._index[(provider, eid)]`. Also if provider is generic (e.g. "sysmon" or "windows"), index by empty string provider `("", eid)` for fallback.
      - `load_rules(self, rules: list[DetectionRule]) -> int`: registers a list of rules.
      - `evaluate_event(self, event: NormalizedEvent, event_db_id: int | None = None) -> list[DetectionMatch]`:
        - Find matching candidates from `self._index`:
          - Check `(event.provider.lower(), event.event_id)`.
          - If provider is Sysmon, check `("sysmon", event.event_id)`.
          - Check `("", event.event_id)`.
        - Combine with `self._universal_rules`, deduplicating by rule ID.
        - Run `compiled.match(event, event_db_id=event_db_id)`.
        - Collect and return non-None matches.
      - `evaluate_batch(self, events: list[NormalizedEvent]) -> list[DetectionMatch]`:
        - Iterates over events, aggregating matches.
      - `persist_matches(self, matches: list[DetectionMatch], alert_repo: AlertRepository) -> list[int]`:
        - For each match:
          - Call `alert_repo.create_alert(**match.to_alert_dict())`.
          - If `match.event_db_id` is present, call `alert_repo.link_alert_evidence(...)`.
        - Return list of created alert IDs.
