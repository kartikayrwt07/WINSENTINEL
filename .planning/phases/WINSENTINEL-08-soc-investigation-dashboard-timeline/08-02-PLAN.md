<description>
1. `app/ui/components/visualizers.py`:
   - `render_svg_process_tree(nodes: list[dict], edges: list[tuple[str, str]], width: int = 900) -> str`:
     - Computes hierarchical positions (tree depths and rank).
     - Renders responsive SVG nodes with rounded rectangles, icons, PID labels, command lines, and threat color borders (crimson for alerted, amber for suspicious, slate for benign).
     - Returns self-contained SVG XML string.
   - `render_svg_timeline(events: list[dict], width: int = 900) -> str`:
     - Renders vertical or horizontal chronological timeline with category icons, timestamps, and title tags.
2. `app/ui/services/process_graph_service.py`:
   - `class ProcessGraphService`:
     - `get_root_processes(computer: str | None = None) -> list[dict]`: Top-level processes.
     - `build_process_tree(process_guid: str) -> dict[str, Any]`: Walks ancestors and descendants using NetworkX, attaches alert badges if process has linked alerts, and formats node and edge payloads for SVG rendering.
3. Unit tests in `tests/unit/ui/test_process_graph_service.py`:
   - Validates NetworkX tree construction from mock process events.
   - Validates SVG generation containing PID, image name, and correct edge connections.
</description>

   - `class TimelineService`:
     - `get_timeline(computer: str | None = None, start_time: datetime | None = None, end_time: datetime | None = None, limit: int = 100) -> list[dict[str, Any]]`:
       - Queries events ordered chronologically.
       - Maps event types to friendly visual badges (Process, Network, File, Registry, DNS, Service).
       - Highlights events linked to alerts.
2. `app/ui/services/persistence_ui_service.py`:
   - `class PersistenceUIService`:
     - `get_persistence_summary(computer: str | None = None) -> dict[str, list[dict[str, Any]]]`:
       - Registry Run / RunOnce keys.
       - IFEO Debugger keys.
       - Windows Services (Security 4697 / Sysmon 6).
       - Scheduled Tasks (Security 4698 / Task Operational).
       - WMI Event Subscriptions (Sysmon 19, 20, 21).
       - Startup folder file creations (Sysmon 11).
3. Unit tests in `tests/unit/ui/`:
   - `test_timeline_service.py`: Tests chronological sorting and category mapping.
   - `test_persistence_ui_service.py`: Tests categorizing persistence mechanisms from raw events.
